P.01 · CS 자동화 칸반보드 — CS-KANBAN

출근 전에,
CS 분석이 끝나 있도록.

매일 아침 개발자들이 하이웍스 공용 메일함을 열어 문의 확인 → 로그 zip 다운로드 → 대조 분석 → 필요하면 IDE로 코드 추적까지 반복했습니다. 이 수동 루틴 전체를 자동화하기로 하고 — 수집부터 AI 진단·답변초안·발송까지 이어지는 파이프라인을 직접 설계·구축해 팀 업무에 연결했습니다.

단계Before · 수동After · 파이프라인효과
문의 확인메일함 수동 확인20분 주기 자동 수집 · 칸반 카드화무인화
로그 분석zip 수동 다운로드·대조자동 해제·파싱 · 개인정보 마스킹자동

시스템 아키텍처 — 문의 수집부터 검토·발송까지 · 스크롤로 조립

01 · 수집

하이웍스 API 리버스 크롤링

DOM 스크래핑 대신 내부 JSON:API를 정찰·재현. 브라우저 없이 세션만 재사용해 수집하고, 대화 단위 시간순 판별로 미답변 문의를 가려냅니다.

02 · 분석

Agentic RAG — 벡터 DB 없이

직접 구축한 사내 위키(진단 규율·정책)를 Claude 헤드리스가 검색하고, 앱 코드 레포와 교차검증. 근거는 페이지 단위로 인용되고, 지식 갱신은 git pull이 전부입니다.

03 · 운영

사내 서버 무인 가동

테일넷 Ubuntu 서버에 systemd 상시 서비스로 배포. 수집→분석→초안이 무인으로 이어지고, 사람은 검토와 발송 승인만 합니다.

P.04 · 안드로이드 오토 플랫폼 확장
